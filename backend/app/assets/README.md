# Risorse grafiche

Metti qui il logo per l'intestazione dei PDF: **`logo.png`** (PNG o JPG rinominato, sfondo trasparente o chiaro,
altezza consigliata 200 px o più). Se il file non c'è, l'intestazione mostra il nome del portale in testo.

Il file viene letto a ogni generazione: non serve riavviare nulla in locale.

**`logo-white.png`** è la versione bianca dello stesso logo: serve per la fascia nera in alto nei PDF. Se un logo personalizzato
non ha la sua versione bianca accanto, nella fascia si appoggia su una piastra chiara.

**`fonts/`** contiene il font **DM Sans** (pesi Light, Regular, Medium e Bold) che i PDF incorporano, con il testo della licenza
**SIL Open Font License 1.1** (`OFL.txt`), che va distribuita insieme ai file. Se i font mancano, i PDF si producono comunque con
Helvetica.
